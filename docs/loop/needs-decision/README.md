# Decisions for the operator

Structural changes go here rather than being decided mid-iteration: a message type the host consumes,
the definitions-file schema, splitting a plugin, anything a host would have to change code for.

One file per decision, named for the question. Each states the problem, the options with their
consequences, a recommendation, and what happens if the decision is deferred.

Deferring is a real option: an iteration that hits one of these records it here, picks a different
item, and keeps going.
